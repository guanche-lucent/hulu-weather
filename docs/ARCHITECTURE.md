# 架构与运行边界

- 前端：Next.js、React、TypeScript；浏览器请求通过同源代理访问后端。
- 后端：FastAPI、Pydantic结构校验、SQLAlchemy；模型适配与费用限制在服务端。
- 认证：当前体验版采用邀请账号与密码、首次改密和服务端会话；权限在后端按用户隔离。
- 任务：观察、今日签、塔罗等请求持久化，处理重试、重复请求和页面返回后的恢复。
- 数据：当前单实例SQLite置于持久卷，云端媒体使用私有对象存储，备份独立保存；不是多实例高可用架构。
- 费用：调用前预留预算，区分应用账本与供应商实扣；不承诺云账单绝对无延迟。
