# 三分钟体验呼噜天气

入口：[hulutianqi.cn](https://hulutianqi.cn/login)。服务器按需开机，目前暂停服务；请先联系向你提供项目的维护者安排体验时间。

1. 使用维护者私下提供的独立账号和初始密码登录，按提示修改密码。当前没有邀请码自助注册。
2. 在“今日”上传一张自己有权使用的猫咪照片，补充现场情况并提交观察。
3. 阅读画面依据与建议，再生成今日签；如要求参考照，先按页面提示保存参考照。
4. 到“故事”打开刚才的记录，验证照片和结果已经保存。
5. 到“塔罗”选择“今日一张”，阅读关系反思；在已保存塔罗中再次查看。

如果仅有一分钟，建议由项目提供者用自己的演示账号展示已有样例；独立面试官账号不会看到演示账号的记录。

生成会消耗模型额度，等待期间不需要反复点击。遇到错误请记下页面提示并联系维护者。不要上传身份证、联系方式等私人信息或无权使用的照片。

新增账号、忘记密码或停用账号，由维护者使用受控工具处理。密码、邀请码和云密钥不放在README、Issue或公开截图中。
